# 🍎 사과 십

이웃한 사과 숫자를 이어 합이 10의 배수가 되면 수확하는 퍼즐 게임입니다.

## 게임 소개

시작 버튼을 누르면 1분 동안 플레이할 수 있어요. 8×8 격자에서 이웃한 사과 숫자를 드래그해 합이 10의 배수가 되면 그만큼 점수를 얻습니다. 수확한 칸 위의 사과는 아래로 내려오고, 위쪽 빈칸은 새 숫자로 채워집니다. 시간이 끝나면 결과 창에서 최종 점수와 최고 점수를 확인할 수 있어요.

## 어떻게 만들었나요

HTML, CSS, Vanilla JavaScript를 각각 별도 파일로 작성했습니다. 포인터 입력으로 마우스와 터치 드래그를 처리하고, `localStorage`에 최고 점수를 저장합니다. 별도 라이브러리나 빌드 과정 없이 동작합니다.

## 실행 방법

저장소의 `index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다.

## 커스터마이징한 부분

8×8 격자, 시작 버튼, 1분 타이머, 모바일 드래그 조작을 적용했습니다. 선명한 사과 아이콘 위에 숫자를 표시하고, 수확한 열은 중력으로 채워 빈칸이 남지 않습니다. 새 최고 기록에는 꽃잎과 꽃가루 컨페티를 재생하고, 결과 창에서 다시 시작할 수 있습니다.
