# 🍎 사과 십

이웃한 숫자 사과를 이어 합이 10의 배수가 되면 수확하는 퍼즐 게임입니다. 1분 동안 사과를 모아 최고 점수에 도전해 보세요!

## 게임 방법

1. **게임 시작**을 눌러 1분 타이머를 시작합니다.
2. 격자에서 상하좌우로 붙어 있는 숫자를 드래그해 이어 선택합니다.
3. 선택한 숫자의 합이 10의 배수일 때 드래그를 놓으면 사과를 수확하고, 합계만큼 점수를 얻습니다.
4. 수확한 자리의 같은 열에서 위쪽 사과들이 아래로 내려옵니다. 위쪽 빈칸은 새 숫자 사과로 채워져 격자는 항상 가득 유지됩니다.
5. 합계가 10의 배수가 아니면 점수를 얻지 못하고 선택이 취소됩니다. 키보드로 칸을 선택할 때는 `Esc`로 선택을 취소할 수 있습니다.
6. 시간이 끝나면 결과 창에서 최종 점수와 최고 점수를 확인하고 다시 시작할 수 있습니다.

최고 점수는 브라우저에 저장되어 다음에 방문해도 유지됩니다. 유효한 조합을 수확할 때마다 꽃가루와 꽃잎이 화면을 가로질러 흩날리는 효과가 나타납니다.

## 주요 기능

- 8×8 격자에 1~9 숫자의 사과를 무작위로 배치
- 마우스·터치 드래그로 상하좌우 인접한 칸 선택
- 합이 10의 배수인 조합을 수확하고 합계만큼 점수 획득
- 수확 후 열 단위로 사과가 내려오는 중력과 새 사과 보충
- 1분 타이머, 현재 점수 및 브라우저에 저장되는 최고 점수
- 게임 시작 화면, 시간 종료 결과 창 및 다시 시작
- 수확할 때마다 재생되는 꽃가루·꽃잎 파티 효과
- 반응형 화면과 숫자를 알아보기 쉽게 표시하는 빨간 사과 아이콘

## 구현

Vanilla JavaScript로 게임 규칙과 입력을 처리하고 HTML, CSS, JavaScript를 각각 별도 파일로 구성했습니다. 최고 점수는 `localStorage`에 저장합니다. 외부 라이브러리나 빌드 과정 없이 동작합니다.

- `index.html` — 게임 화면과 접근성 있는 결과 창
- `style.css` — 반응형 레이아웃, 사과 디자인과 애니메이션
- `game.js` — 보드, 드래그 선택, 점수, 타이머, 수확 및 기록 저장

## 실행 방법

저장소의 `index.html`을 최신 브라우저에서 열고 **게임 시작**을 누르면 플레이할 수 있습니다. 별도 설치나 서버 실행은 필요하지 않습니다.
